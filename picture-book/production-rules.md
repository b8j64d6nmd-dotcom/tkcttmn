# えほんどうが 制作ルール

## 対象
- 2〜3さいを中心とした小さな子ども。
- むずかしい漢字・抽象語・説明的な教訓は使わない。
- 基本はひらがな。短く、耳で聞いて分かることばにする。

## 教育設計
- 大人が「こう考えてほしい」という結論を書かない。
- 「みんなちがってすてき」「できなくてもだいじょうぶ」等の教訓を直接言わせない。
- 出来事・表情・間を見せ、子ども自身が気づける余白を残す。
- 「問い → 少し待つ → 次のページで出来事」のリズムを使う。
- テストのような質問は避ける。
- 絵で分かることをナレーションで重ねて説明しない。

## シリーズの基本構造
1. どうぶつAにできること。
2. どうぶつBにできること。
3. にんげんにできること。
4. 優劣や結論をつけず、余韻を残して終える。

## 画像
- 1ページ = 1枚の独立画像。
- 横長16:9。
- 18ページを1枚のコラージュにしない。
- ページ番号を画像内に入れない。
- Canvaへ送る前に、全ページを1枚ずつ完成させる。
- キャラクターの顔・体型・色・画風を全ページで統一。
- 手描き感のある、オリジナリティの高い絵本調。
- AI画像らしい均一な質感を避ける。
- 重要な人物・動物・文字を端に置かず、安全余白を取る。
- Canvaで16:9に配置しても切れない構図にする。

## Canva
- 画像を無理にトリミングして16:9化しない。
- 完成した16:9画像を1ページにつき1枚配置。
- ページ番号なし。
- 動画化を前提にする。
- ナレーションはやさしい女性声を想定。
- 問いかけの後には子どもが考えられる「間」を作る。
